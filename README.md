# TamilCrafters Packs

Static download hub for Tamilcrafters packs. Plain HTML, CSS and JavaScript.

## Deploy
Repo Settings > Pages > Deploy from branch > main > / (root).

## Add or edit a pack
Edit `packs.json` (id, title, edition, type, summary, image, page, download). Array order is the "Popular first" order.
